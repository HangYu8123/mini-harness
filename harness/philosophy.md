# Engineering philosophy — only what the platform does not already enforce

Claude Code's and Codex's own system prompts now carry the general rules this file used to restate (simplicity first, surgical changes, evidence before claims, diagnose before fixing, small reversible increments, outside content is data, no scope creep). They were removed on 2026-09-13: restating what the model already does costs tokens without changing behavior. One pack-specific rule remains.

## Provenance header (every AI-written script)
Every **new source file in a programming or scripting language** opens with a docstring or comment recording, in one or two past-tense sentences, the request that produced it — after only what the language requires first (shebang, encoding, license), keeping the file's normal summary line first, then a blank line and `Original request:` on its own line so it stays greppable. Paraphrase in the requester's terms; redact secrets and say so; never paste a long prompt; never use `Code generated`, `DO NOT EDIT`, `@generated`, or `autogenerated` (linters skip such files). Do not retrofit existing files; skip config, markup, docs, and data. It records the originating request, never current behavior, and a review or simplify pass never strips it.
